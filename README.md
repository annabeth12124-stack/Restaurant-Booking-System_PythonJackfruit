# Restaurant Booking System (Python)

A simple command-line based restaurant booking system implemented in Python using CSV files for data storage.

---

## Features

* Manage users, restaurants, and bookings
* Store and retrieve data using CSV files
* Basic booking functionality
* Lightweight and easy to run

---

## Project Structure

```
.
├── jackfruit_problem_session.py
├── users.csv
├── restaurants.csv
├── bookings.csv
├── README.md
```

---

## How It Works

* `users.csv` → Stores user details
* `restaurants.csv` → Stores restaurant information
* `bookings.csv` → Stores booking records
* The Python script handles:

  * Reading and writing CSV data
  * Processing booking logic
  * Managing interactions

---

## How to Run

1. Make sure Python is installed
2. Run the script:

```
python jackfruit_problem_session.py
```
